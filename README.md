# HumanOS Runtime UseCases

Collection of HumanOS Runtime Examples and UseCases.

## Tooling

To run most use cases following tools are required:

- [HumanOS IoT Designer](https://data.cybertech.swiss/public.php/dav/files/LgBzNjG2wtRPXFM/?accept=zip) (also includes the trial runtime)

Further, following tools might support you:

- FANUC NC Guide
- Heidenhain Simulators for iTNC530 or TNC640
- Mosquitto Broker and MQTT Explorer
- UAExpert from Unified Automation
