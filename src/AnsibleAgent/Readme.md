# Ansible Agent

The ansible agent is part of ICT automation platform. It can be used to pass dynamic inventory to Semaphore API for [ansible](https://docs.ansible.com/) tasks.

The demo project also includes the workflow engine to integrate the agent into [HumanOS Platform Pipelines](https://doc.cybertech.swiss/platform/intro).
